# Bluetooth Input Demo

这是一个用于测试蓝牙键盘输入光标跟随问题的Flutter测试应用。

## 问题描述

在安卓iPad设备上使用蓝牙键盘输入时，存在光标位置和键盘预输入文本不能正确跟随的问题。

## 功能特性

- ✅ 支持安卓和iOS平台
- ✅ 单行文本输入测试
- ✅ 多行文本输入测试
- ✅ 实时状态显示
- ✅ 光标位置调试
- ✅ 简洁的UI界面

## 使用方法

1. 连接蓝牙键盘到测试设备
2. 启动应用
3. 在输入框中使用蓝牙键盘输入文本
4. 观察光标跟随情况和预输入文本位置

## 运行应用

```bash
# 进入项目目录
cd /Users/wangjinshan/my_flutter_engin/3.29.0/examples/bluetooth_demo

# 安卓平台
../../bin/flutter run -d android

# iOS平台
../../bin/flutter run -d ios
```
